# 실험 전 레포트: 피에조 단일 음 발생기

작성일 2026-09-25.

## 1. 동작 원리와 핵심 파라미터 계산

### 동작 원리
온보드 50 MHz 고속 메인 클록을 분주하여 피에조 스피커(Piezoelectric Buzzer)의 구동 주파수인 294 Hz(음계 '레', D4) 사각파를 생성한다. 피에조 부저는 인가되는 사각파의 주파수에 따라 세라믹 진동판이 물리적으로 진동하며 해당 음역대의 소리를 발생시킨다. 완전한 50% 듀티비의 대칭 사각파를 만들기 위해 전체 주기가 아닌 '반주기(Half Period)'를 카운팅한 후 출력 신호(`piezo`)를 토글(~piezo)하는 방식을 적용한다.

### 핵심 파라미터 계산
1. **목표 주파수 및 반주기 카운트 (`HALF_PERIOD`)**:
   - 입력 주 클록 주파수 $f_{\mathrm{clk}} = 50\text{ MHz} = 50,000,000\text{ Hz}$
   - 목표 출력 톤 주파수 $f_{\mathrm{tone}} = 294\text{ Hz}$ (4옥타브 레, D4)
   - 1전체 주기 시간 $T = \frac{1}{294}\text{ s} \approx 3.401\text{ ms}$
   - 1반주기당 필요한 클록 수:
     $$\text{HALF\_PERIOD} = \frac{f_{\mathrm{clk}}}{2 \times f_{\mathrm{tone}}} = \frac{50,000,000}{2 \times 294} = \frac{50,000,000}{588} \approx 85,034\text{ cycles}$$
   - 카운터 레지스터 비트 폭:
     $$\text{COUNT\_WIDTH} = \lceil\log_2(85,034)\rceil = 17\text{ bits}$$
($2^{16} = 65,536 < 85,034 \le 2^{17} = 131,072$)
   - 카운터는 0부터 $\text{HALF\_PERIOD}-1$인 85,033까지 계수한 후 0으로 리셋되며 `piezo` 출력을 반전시킨다.

2. **시뮬레이션 축소 파라미터 계산**:
   - 빠른 기능 검증을 위해 `CLK_HZ = 1000`, `TONE_HZ = 100`으로 축소 인가한다.
   - 축소된 반주기 클록 수:
     $$\text{HALF\_PERIOD}_{\mathrm{sim}} = \frac{1000}{2 \times 100} = 5\text{ cycles}$$
   - 따라서 시뮬레이션에서는 5클록마다 출력이 반전되어 1주기가 10클록(200 ns)으로 동작하게 된다.

| 검사 항목 | 검사 조건 | 기대값 | 판정 기준 및 검증 의미 |

## 4. 시뮬레이션 결과 및 수정 실험

### 정상 시뮬레이션 확인
- **[종료 로그](../../evidence/03/vscode/simulation.txt)**: `LAB3_PIEZO_PASS edges=5`, 종료 시각 `551000 ps (551 ns)`
- **[파형 분석](../../evidence/03/vscode/wave.png)**:
  - `rst_p`가 1인 0~50 ns 구간에서는 `piezo=0`, `count=0`으로 유지된다.
  - 50 ns 직후 리셋이 해제되면 `count`가 0부터 4까지 1씩 증가하고, 5번째 에지에서 출력이 반전되면서 `count`가 다시 0으로 복귀한다.
  - 25클록이 진행되는 동안 출력이 정확히 5클록 간격으로 Low $\rightarrow$ High $\rightarrow$ Low를 반복하여 총 5회의 반전 에지(`edges=5`)를 기록한다.

### 수정 실험 (오류 주입 및 복구)
`TONE_HZ`를 100에서 125(또는 다른 주파수)로 변경하여 분주값 변화 시 테스트벤치가 주기 불일치를 감지하는지 점검한다.

| 실험 단계 | 설정 내용 | 기대 동작 | 실제 실행 결과 | 비고 |
|---|---|---|---|---|
| 정상 실행 | `CLK_HZ=1000, TONE_HZ=100` | 반주기 5클록 간격 | `LAB3_PIEZO_PASS edges=5` (551 ns 종료) | 정상 통과 |
| 고장 주입 | `TONE_HZ=125` 로 변경 | 반주기가 $\frac{1000}{250}=4$클록으로 단축 | `half period=4` 오류 감지, `$fatal` 강제 중단 | 테스트벤치 검증 유효성 확인 |
| 원복 복구 | `TONE_HZ=100` 복원 | 반주기 5클록 복원 | `LAB3_PIEZO_PASS edges=5` 복구 | 정상 확인 |

## 5. 보드 실험 계획 및 관찰 항목

### 하드웨어 환경 및 핀 매핑
- **타깃 FPGA**: Spartan-7 `xc7s75fgga484-1`
- **클록 및 리셋**: 온보드 50 MHz 클록 발진기 (B6 핀), 리셋 푸시버튼 K4
- **피에조 출력 핀**: Y21 포트

### 보드 관찰 절차
1. Vivado Hardware Manager를 통해 비트스트림(`lab3_piezo.bit`)을 다운로드한다.
2. 다운로드가 완료되는 즉시 Y21 핀에 연결된 온보드 피에조 스피커에서 294 Hz 주파수에 해당하는 맑은 단일 음('레')이 지속적으로 출력되는지 청각적으로 확인한다.
3. K4 리셋 버튼을 누르고 있는 동안에는 발음이 즉시 중단(소등/무음)되는지 확인하고, 버튼을 떼면 즉시 정상적인 단일 음 출력이 재개되는지 계측한다.
4. 오실로스코프 또는 로직 아날라이저를 Y21 핀에 프로빙하여 실제 출력 파형의 주파수가 294 Hz($\pm 1\text{ Hz}$ 오차 범위 이내)이며 듀티비가 정확히 50%인지 관찰하고 사진/영상을 촬영한다.
